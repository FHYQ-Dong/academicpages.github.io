This project involved designing a 5-stage pipelined MIPS CPU in Verilog. I utilized iverilog and GTKWave for comprehensive behavioral simulation to resolve pipeline hazards and subsequently deployed the architecture on an FPGA via Vivado. The system was optimized to accelerate sparse matrix multiplication workloads, with hardware correctness validated through testbenches and real-time result visualization on a BCD7 display.
