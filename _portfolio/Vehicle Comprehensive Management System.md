Developed a distributed client-server vehicle management platform using Object-Oriented C++ and Qt6. The server architecture implements a custom HTTP backend with cpp-httplib and nlohmann/json, utilizing std::map-based indexing pools to achieve O(log n) efficiency for data retrieval. I integrated security features including salted SHA-256 password hashing and Base64 image serialization, and validated system stability across Windows and Linux environments through extensive GoogleTest unit testing and Postman API verification.
