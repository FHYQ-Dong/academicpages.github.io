I developed a full-link communication system simulator implementing rate-1/2 and 1/3 convolutional codes with Viterbi decoding (hard/soft decision) to analyze BER performance against SNR. Extending beyond standard requirements, I integrated a custom encryption module with joint source-channel coding pipelines to evaluate the trade-off between transmission security and image recovery quality under constrained channel capacity.
