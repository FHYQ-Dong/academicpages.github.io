As part of the Deep Learning course, I proposed SBSPO, a self-bootstrapping alignment framework for LLaVA 1.5. The project utilized a novel Reward Union strategy to mitigate feedback length bias without external supervision. The method achieved an 81.2% reduction in object hallucination on Object HalBench, significantly outperforming proprietary models like GPT-4V in trustworthiness benchmarks.
